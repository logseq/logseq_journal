# OCaml Review

只读审查请求范围内的代码，只报告问题，不修改代码或其他文件。

1. 检查读写放大：单次操作是否重复全量读取、遍历或重写，结合数据量与调用频率判断影响。
2. `List` 仅用于明确小于 1000 项的数据，数量未知或可能 >= 1000 时应改用 `rrbvec`（已有依赖时使用 `Rrbvec` 向量），重点检查高频 `List.length`、`List.nth`、`List.append`、`List.concat` 等线性调用及重复拼接造成的 O(n²)。
3. 检查 `spec/` 下的 `.mli` 类型能否加强约束，以排除非法状态、区分身份与生命周期并限制构造权限。

仅报告有证据的问题，每点尽量一句，包含严重度、位置、触发条件与影响，并标明实证或推断；无发现时明确说明。
